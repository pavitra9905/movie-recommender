# Movie Recommendation System

A Flask web application that recommends movies based on genre and rating similarity.

## Live Demo
https://movie-recommender-pg4q.onrender.com

## Tech Stack
- Python, Flask, SQLite, Pandas, OMDB API
- Deployed on Render

## Features
- Fetch real-time movie data from OMDB API
- Content-based filtering recommendation engine
- REST API with 4 endpoints
- Frontend UI to search and add movies
